# wordpress
معرض اعمالي لمواقع وردبريس

## قالب مخصص لموقع رتائب
تمت إضافة قالب جاهز باسم `rtaibah-dashboard-theme` داخل المسار:

`wp-content/themes/rtaibah-dashboard-theme`

### المميزات
- واجهة عربية RTL للواجهة الأمامية.
- صفحة رئيسية تحتوي قسم ترحيبي + بطاقات مؤشرات.
- إعدادات عبر `Customizer` لتعديل عنوان/وصف القسم الرئيسي.
- لوحة تحكم تفاعلية داخل إدارة ووردبريس بعنوان **لوحة رتائب**.
- تحديث تلقائي للمؤشرات كل 30 ثانية (مقالات، صفحات، مستخدمون، تعليقات).

### طريقة التشغيل
1. انسخ مجلد القالب إلى موقع ووردبريس الفعلي.
2. من لوحة التحكم > المظهر > القوالب > فعّل قالب **Rtaibah Interactive Theme**.
3. افتح صفحة **لوحة رتائب** من القائمة الجانبية لمتابعة المؤشرات التفاعلية.
